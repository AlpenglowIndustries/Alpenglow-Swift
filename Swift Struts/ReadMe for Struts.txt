A word about different strut configurations for anyone wanting to cut replacement struts for Alpenglow swifts.  Between the beta group and some production configuration changes to improve durability, there ended up being 4 versions of struts delivered.

Short Struts, Small Hole  <-- only 1 swift has this oddball, S/N 255
Short Struts, Big Hole    <-- original beta version & first 10 one-of-a-kind ones sold
Long Struts, Small Hole   <-- final production version
Long Struts, Big Hole	  <-- early production version

How to tell what configuration a swift is:

Strut length, measured tip to tip:
- Short struts = 13.75"
- Long struts = 14.25"

Small and Big hole refers to the center hole that the strut pin goes through.  Swifts originally shipped with pins that needed a 0.25" diameter hole (Big hole).  We eventually found pins with smaller diameters that only needed a 0.095" diameter hole (Small hole).  It's difficult to tell which pin it is if the struts are all intact, as the pin heads are about the same size on both styles.  But if a strut is broken, the difference in hole size is pretty obvious.  

We do have records that indicate the configuration of each serial number of swift, see the Swift SN Config List spreadsheet in the main folder.  They are not 100% complete, but are very close.  The serial number is lightly laser-marked on the shaft, on the part that's inside of the clamp.  It's easy to find, just unscrew the knob on the clamp to remove it.  VERY generally speaking, S/Ns 1-289 have big holes, 290-312 are in the transition zone with some big and some small, and S/Ns 313-653 have small holes, but THERE ARE EXCEPTIONS.

You will need a box to ship replacement struts in.  I like EcoEnclose as a company, and I haven't found anyone willing to make small quantities of custom box sizes for cheaper.
